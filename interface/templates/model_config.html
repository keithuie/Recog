Detection Parameters

Kernel Type

Core

Shape of the kernel used for pattern matching

Triangular: Sharp response for sudden changes
Parabolic: Smoother for gradual variations

Number of Bins

Resolution

Histogram resolution for each channel

More bins = higher resolution but needs more training data. 64 is recommended for most applications.

Kernel Width

0.5

Width relative to bin width (sensitivity)

Sensitive Tolerant
Lower (0.3-0.5): More sensitive to exact matches
Higher (0.7-1.0): More tolerant of variation

Anomaly Threshold

0.3

Match strength below which triggers alert

More Alerts Fewer Alerts
Start with 0.3 and adjust based on false positive rate. Lower = more sensitive.
